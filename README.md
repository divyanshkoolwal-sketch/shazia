# sházia — the Shazia health wearable

**Live site: [sházia.com](https://xn--shzia-yqa.com/)**

sházia (also written *Shazia*) is a women’s health wearable: a gold-tone bracelet set with nine octagon-cut green stones, with a health sensor hidden on the inside. It is built for perimenopause and menopause.

- Tracks every hot flash and your period
- Shows whether your treatment is working
- Writes a report for your doctor
- Does everything a fitness tracker does

This repository holds the landing page served at https://xn--shzia-yqa.com/ (the internationalised domain name for sházia.com). It is a single static page deployed on Vercel; fitting requests from the form are stored in Supabase.
